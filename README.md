# 发票号查询（GitHub Pages 对外包）

只上传这个文件夹里的文件，不要上传 data.json / users.json。

1. GitHub 新建仓库（建议私有仓库 + Pages；个人免费账号通常只能公开仓库）
2. 把本目录全部文件传上去
3. Settings → Pages → Deploy from a branch → main / root
4. 把 https://你的用户名.github.io/仓库名/ 发给外人

登录：
- 管理员 ADMIN / ADMIN
- 供应商用工厂代码，如 A379 / A379

路人没有账号进不去表格。会下载 vault.json 的人仍可能猜弱密码，这是静态站的上限。
